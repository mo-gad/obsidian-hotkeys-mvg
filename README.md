# obsidian-hotkeys-mvg

Personal Obsidian plugin with editor commands:

| Command | Default hotkey | Description |
|---|---|---|
| Delete current line | `Cmd+Shift+K` | Deletes the current line (or selected lines), preserving cursor column |
| Duplicate line(s) up | `Alt+Shift+Up` | Copies current line (or selection) above |
| Duplicate line(s) down | `Alt+Shift+Down` | Copies current line (or selection) below |

## Installation

Install via [BRAT](https://github.com/TfTHacker/obsidian42-brat): add `mo-gad/obsidian-hotkeys-mvg` as a beta plugin.
